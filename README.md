## 什么决定了专线网络价格

同一条“10M专线”，不同服务商报价能差出好几倍，因为报价由七个变量共同决定。

1. **带宽大小**：常见独享带宽从5M、10M到50M、100M以上。带宽越大总价越高，但折算到每兆的单价通常越低。
2. **目标国家和地区**：香港、日本、新加坡、美国、欧洲、东南亚、中东的线路成本各不相同。同样带宽，中东、非洲方向一般更贵。
3. **线路类型**：IPLC、IEPL、MPLS偏向传统固定专线，SD-WAN可以统一调度多节点资源。询价前先确认双方比的是同一种方案。
4. **独享还是共享**：价差最大的变量，后面单独展开。
5. **IP类型**：共享IP、独享静态IP、原生IP、住宅IP价格不同，要多个国家的独享住宅IP，费用会上浮。
6. **是否多地组网**：总部连分公司、连海外办公室的多节点组网，按节点数量、地区、带宽和设备综合计费。
7. **SLA和售后**：跨境直播、生产系统这类业务对连续性要求高，服务等级承诺越高，价格越贵。

租期是第八个显性变量：租用期限越长，单价越低。国内专线实行市场调节价，各地市场竞争程度不同，同一带宽在不同城市的报价差异很大，这也是专线价格没有标准答案的根本原因。

## 独享和共享，是专线网络价格里最大的水分来源

100M共享带宽和100M独享带宽是两种产品。共享线路由多个用户分摊网络资源，所以便宜；企业独享专线按约定提供独享带宽，费用明显更高。市场上几百元的“100M跨境网络”，不能拿去和10M独享专线的报价直接比较，两者只是恰好都带了个数字而已。

询价时把三个问题钉死：带宽是独享还是共享、有没有超卖、SLA什么等级。只有在相同地区、相同带宽类型、相近SLA和IP条件下，比价才有意义。

独享线路贵在哪，技术社区里有人讲得很直白：只要不超卖，IEPL这类独享光纤专线的品质上限高于CMI、9929、GIA这些精品公网优化线路。道理不复杂——公网再优化也是大家共享的管道，专线是一根独享的光纤。同样是“提速”，一根不超卖的独享线路贵出数倍，成本就贵在这里。

## 你需要多大带宽？两个现成的估算方法

办公上网按人均1-2Mbit估算，业务专线按并发访问量算，多数中小企业用这两个算法就能框出带宽范围。

方法一，办公上网：员工人数乘以1-2Mbit。100人的办公室，办公带宽需要100M到200M。这种情况一般不建议全走专线，更省钱的组合是业务主机走专线，员工上网走普通商宽，必要时再加一条网络加速线路。

方法二，业务专线：按分支机构并发访问计算。比如2台OA系统要供10个分支机构同时访问，按每个分支100KB字节计算，100×10×8=8Mbit，一条10M专线就足够。专线资源应该留给服务器和业务主机，这条原则能帮你省掉一大半预算。

跨境场景再具体一点：几个人日常外贸办公，账号版方案足够；10人左右的团队，5M独享专线是常见起点；20人以上，或者涉及海外直播、AI研发这类高并发、大流量业务，再往10M、20M、50M看。

## 合规和办理：两条合法路径，两个省钱渠道

跨境专线目前只有两种合法接入方式。一是通过移动、联通、电信三大运营商申请国际专线接入，物理专线、速度快、稳定，代价是施工周期长、价格贵；二是通过持有电信主管部门批准的电信业务经营许可的第三方办理SD-WAN，接入方式多，价格低不少。市面上提供跨境联网服务的商家鱼龙混杂，有关部门也在整治查处扰乱市场的行为，选服务商先核资质。

办理国内企业专线需要准备公司营业执照复印件、经办人身份证复印件等材料并盖公章。想省钱的话，通过企业宽带服务商办理通常比直接去营业厅便宜，而且一般提供上门服务。

## 常见问题

**企业专线和普通企业宽带有什么区别？**
企业宽带是供企业单独使用的一条专门线路，下行大于上行，多数情况拿不到固定公网IP；企业专线上下行速率对称，并配有多个固定IP，可以对接服务器，同时开启8080、443等对外访问端口。需要对外提供服务就选企业专线，纯粹办公上网用企业宽带更划算。

**专线为什么比家用宽带贵这么多？**
独享带宽、固定IP、SLA保障三项成本摆在那里。家用宽带是一条大管道分给很多用户共享，专线是独享资源，还要承诺故障响应和服务等级，价格不在一个量级。

**专线价格还能谈吗？**
能。租期越长，折算单价越低；带宽越大，每兆单价也越低。通过企业宽带服务商办理，报价通常也低于营业厅。

**看到几百元一年的“专线”能买吗？**
先问三个问题：独享还是共享？有没有超卖？有没有电信业务经营许可？三个都答不清楚，慎重。
